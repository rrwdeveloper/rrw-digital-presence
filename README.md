# RRW Digital Presence

Build a professional, modern, premium website for a digital web development service brand called "RRW".

BRAND
Brand Name: RRW
Tagline: "We Build Your Digital Presence"

RRW provides professional website and web application development services for businesses, organizations, schools, communities, and other digital needs.

IMPORTANT:
This website is NOT a digital recreation of a pamphlet.
The pamphlet is only a reference for the service categories and pricing.

Create a completely original website experience with a professional digital agency/development studio aesthetic.

Do NOT copy any existing website, layout, branding, illustration, or visual identity.

==================================================
1. TECHNOLOGY & BACKEND
==================================================

Use:

- React
- TypeScript
- Tailwind CSS
- Modern reusable component architecture
- Lovable Cloud for backend infrastructure
- Lovable Cloud database
- Lovable Cloud authentication
- Lovable Cloud storage where needed for images/files

IMPORTANT:
Do not use an external backend service.

The website must be a real working application, not only a visual prototype.

The CMS/Admin system is an essential part of the project and must be implemented from the beginning.

Do NOT build a completely hardcoded frontend and add the CMS afterward.

First establish the database structure and CMS architecture, then connect the public website to the CMS data.
